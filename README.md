## [실습 목표]
1. 녹음 → STT → 응답 생성 → TTS → 재생' 흐름을 하나의 실제 서비스 시나리오로 확장
2. Git Repository 생성
3. Render에 코드 배포
4. Neon에 데이터베이스 생성
5. End-point에서 테스트

## [완성 화면의 동작]
1. Streamlit에서 마이크로 음성을 녹음합니다.
2. 데모 STT 또는 실제 faster-whisper를 선택합니다.
3. 안내할 시설(도서관, 학생식당, 취업지원센터, 행정실)에 대한
4. 한국어 질문을 인식합니다.
5. 사용자의 질문에서 시설명을 찾아 운영 안내를 반환합니다.
6. 생성한 답변을 비프음 데모 또는 실제 edge-tts로 출력합니다.
7. STT/응답/TTS/총 처리시간을 측정하고 막대그래프를 표시합니다.
8. 개인정보를 제외한 실행 이력을 JSONL에 저장합니다.
9. 최근 처리 이력을 표로 확인합니다.

## [파일]
day37_practice.py: 통합 실습 완성 코드
voice_runs_campus.jsonl: 실행 시 자동으로 생성되는 이력

## [구현 절차]
### ① day37_ex.py에서 입력, 모델 호출, 메타데이터 저장 흐름을 확인합니다.
### ② 시설 정보는 파이썬 딕셔너리로 정의합니다(운영시간은 연습용 예시).
### ③ 답변 생성 함수를 만들고 시설명이 들어간 질문에 대응합니다.
### ④ 인식되지 않은 질문은 선택 가능한 시설 목록을 안내합니다.
### ⑤ 음성 녹음 여부 및 10MBytes 용량 제한을 검사합니다.
### ⑥ 모델 실행 중 오류가 발생하면 원인을 표시하되 앱이 중단되지 않도록 합니다.
### ⑦ 각 단계 수행 시간을 perf_counter()로 측정합니다.
### ⑧ 요청 ID, 시각, 사용 모델, 오류 여부, 처리시간을 JSONL로 기록합니다.
### ⑨ Streamlit에서 음성 결과, 구간별 소요시간, 최근 이력을 확인합니다.

## [확인 시나리오]
예시 문장 '도서관 운영시간 알려줘' → 도서관 안내
'학생식당 어디야?' → 학생식당 안내
'취업지원센터 이용하고 싶어' → 취업지원센터 안내
'운동장에 대해서 알려줘' → 안내 가능한 시설 목록 표시
녹음을 하지 않고 실행 → 오류 메시지, 처리하지 않음
실제 TTS 사용 → 문장을 읽는 mp3 생성(인터넷 연결 필요)
실제 STT 사용 → 입력 WAV를 음성 인식(최초 모델 다운로드 필요)
